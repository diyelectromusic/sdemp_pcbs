# Arduino 62256 SRAM Testre

A shield for an Arduino Uno to allow it to do basic tests on 62256 SRAM memory.

- Design and build notes: https://emalliab.wordpress.com/2026/09/19/arduino-62256-sram-tester/

Bill of Materials:
- Arduino SRAM Tester Shield PCB.
- Arduino Uno
- 1x 74HC383 (LS or HCT probably ok too?)
- 1x 28pin WDIP ZIF socket
- 2x 100nF ceramic capacitors
- 3x 1Kx9 pin resistor network
- 23x 3mm rectangular LEDs (colours to taste)
- Optional: 1x 14pin DIP socket
- Pin headers

Errata:
- None
