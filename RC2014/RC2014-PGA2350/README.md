# RC2014 PGA2350 Breakout

A breakout board for the Pimoroni PGA2350 RP2350 module in RC2014 format, with all RC2014 signals connected to the PGA2350.

- Design and build notes: https://emalliab.wordpress.com/2026/06/20/watching-a-z80-bus-from-an-rp2350-part-3/

Bill of Materials:
- RC2014-PGA2350 PCB
- Pimoroni PGA2350.
- Micro USB socket – see PCB and photos for footprint.
- Optional: 9 pin 8-way 1K resistor network (for LEDS).
- Optional: 8x 3mm rectangular LEDs (colours to taste)
- 2x 2-pin tactile switches – see PCB and photos for footprint
- 40-way right angle pin headers.
- 40-way 2×40 round pin header sockets, cut to four 2×8 pieces.
- Pin headers.
- Header Jumper.

Errata:
- Could have used an easier way to attach a USB socket...
