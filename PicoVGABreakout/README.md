# Pico VGA Breakout

A VGA signal breakout board designed principly for use with 3V3 microcontrollers, but not exclusively.

- Design and build notes: https://emalliab.wordpress.com/2026/08/01/simplified-pico-vga-part-2/

Bill of Materials:

- Pico VGA Breakout PCB
- VGA socket - PCB Mounted
- Pin headers
- Range of resistors and diodes to taste (see notes above).

Errata:
- The silkscreen details the use of 300R resistors for the RGBY1111 mode, but it requires 330R.
